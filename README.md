# Temperate Island

Terrain generator for the temperate climate in Transport Fever 3. It builds an island with a varied coast, inland lakes, rivers, and mountains. Forests and alpine conifers follow the height and biome layout.

The generator is named **Temperate Island** and appears in the map generator list when starting a new game.

## Options

Each slider runs from Sparse to Packed. The default is Dense.

- **Lakes** — how many lakes appear
- **Rivers** — how many rivers appear
- **Mountains** — how many mountains appear, and how high they are

## Install

Subscribe to the mod in the in-game Mod Hub once it is published.

To try a local copy, put this folder in the game's manual mods directory. On Steam that is:

`Steam/userdata/<Steam ID>/3493540/local/mods/`

The folder name may only use letters, numbers, underscores, and spaces. `temperate_island_generator` should be a safe name.
